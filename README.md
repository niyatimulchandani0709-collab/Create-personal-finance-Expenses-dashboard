# Create-personal-finance-Expenses-dashboard
Created a professional personal finance and expenses dashboard to track income, expenses, spending categories, savings, and key financial metrics using Excel.
💰 Personal Finance & Expenses Dashboard

📌 Project Overview

The Personal Finance & Expenses Dashboard is an Excel-based financial analysis project designed to track income, monitor expenses, analyze savings, compare budgets with actual spending, and track financial goals.

The project converts structured personal finance data into meaningful insights using analysis tables, KPIs, charts, and an interactive dashboard.

---

🎯 Project Objectives

- Analyze personal income and expenses
- Track monthly financial performance
- Monitor spending by category
- Compare budget vs actual expenses
- Analyze monthly savings
- Track financial goals
- Monitor key financial KPIs
- Visualize income, expenses, and savings trends

📊 Data Analysis Tables

1. Income Analysis Table

Analyzes income sources and monthly income performance.

2. Expense Analysis Table

Analyzes expenses by category and identifies major spending areas.

3. Monthly Summary Table

Provides a monthly overview of income, expenses, savings, and financial performance.

4. Budget vs Actual Table

Compares planned budget with actual spending and identifies budget variances.

5. Savings & Financial Goals Table

Tracks savings progress and monitors progress toward financial goals.

6. Dashboard KPI Table

Summarizes important financial metrics such as:

- Total Income
- Total Expenses
- Total Savings
- Savings Rate
- Budget Variance
- Average Monthly Expense
- Financial Goal Progress

📈 Dashboard Charts
